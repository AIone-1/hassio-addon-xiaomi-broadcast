# Changelog

## 1.0.8 (2026-08-06)

- 🔍 传感器候选按关键词预过滤：温度/湿度/用电/门窗各看对应词，候选从 500+ 缩到几十个
- ✏️ 修复手动添加：实体 id 输入框可编辑（原来 readonly 写不进）
- 🐛 修复"只看文字点第二次提示播报进行中"：文字模式不再抢锁，可随时反复点

## 1.0.7 (2026-08-06)

- ☀️ 主题切换：白天/夜晚模式（右上角按钮，偏好存后端）
- 🗑️ 日志清空按钮
- 🔍 搜索框优化：点开显示全部候选，输入关键词才过滤

## 1.0.6 (2026-08-06)

- 🔍 传感器配置页每个类别加搜索框：输入关键词过滤实体，点击候选直接添加（实体太多也找得到）
- 📝 播报页加"播报文字"区：点「只看文字」后轮询 /state 显示生成内容
- 🔧 实体条目改为只读输入框（实体 id）+ 房间名输入框，不再用巨大下拉

## 1.0.5 (2026-08-06)

- 🐛 修复"无 HA token"：SUPERVISOR_TOKEN 拿不到时自动 fallback 到设置页的 ha_token（手动兜底）

## 1.0.4 (2026-08-06)

- 🐛 实体下拉改为 `/cfg/` 路径（避免 ingress 下 `/api/` 嵌套被 HA 拦截），兼容旧 `/api/`
- 🔍 实体加载失败时显示具体错误原因（此前静默返回空）

## 1.0.3 (2026-08-06)

- 🐛 修复 Web UI 实体下拉为空：ingress 下前端用相对路径（BASE 前缀），避免 `/api/` 请求被 HA 主 API 拦截

## 1.0.2 (2026-08-06)

- ⚙️ Web UI 新增「传感器配置」页面：在加载项网页上直接选实体、填房间名，保存即生效，无需 Samba 编辑 JSON
- 🔒 配置保存只写实体映射，DeepSeek key 由加载项设置页管理，不落盘到可编辑 JSON

## 1.0.1 (2026-08-06)

- 🐛 修复 Docker 构建：添加 build.yaml 指定 build_from 基础镜像

## 1.0.0 (2026-08-06)

- 🎉 首个版本：小爱每日播报加载项
- 每日播报 + 周/月/年周期总结
- 大模型引擎直连 DeepSeek（Anthropic 兼容端点）
- 加载项侧边栏 Web UI（日志 / 触发 / 只看文字）
- 支持 HA 自动化 rest_command 触发（/trigger）
- 终端任务计数接口（/task）
- 配置通过 Samba 编辑 `/share/xiaomi_broadcast/`，或加载项设置页
