# 🎙️ 小爱每日播报 — 使用文档

把家里传感器状态生成中文播报稿，推到小米音箱朗读。支持每日/周/月/年播报、大模型引擎、可视化配置。

## 📖 六个功能页面

### 📢 播报页

播报页是主操作界面：

- **类型选择**：日 / 周 / 月 / 年（决定播报哪种总结）
- **引擎切换**：模板（规则模板） / 大模型（AI 生成）
- **句间停顿**：每句播完等多久再念下一句（0.3s~1.5s），避免打断
- **📢 语音播报**：让音箱念（字幕同步）
- **📝 文字播报**：只生成文字不发声（测试用）
- **日志**：实时日志，按类型分色（❌红/✅绿/⚠️黄/📢蓝/🤖紫）
- **统计**：传感器总数、离线数、已统计天数

### 📋 播报栏目页

选**哪些内容**参与播报，改完自动保存，**模板和大模型都生效**：

- 问候语 / 结束语 / 播报结束
- 温度 / 湿度 / 耗电量 / 实时功率
- 安全 / 空气质量 / 灯光
- 终端任务 / 待办备忘 / 设备故障
- 鼓励语 / 小贴士

某个栏目不需要就取消勾选，播报就不会有它。

### ⚙️ 传感器配置页

把家里的传感器映射到各分类：

- **图形化选实体**：搜索框过滤，点候选添加
- **每行**：实体id → 播报名（可空）→ 房间名 → 用途 → 用电方式（仅用电）
- **播报名**：填什么播什么（如"冰箱"或"客厅冰箱"），同房间多设备不混淆
- **拖动排序**：⠿ 抓手拖动调整播报顺序
- **🔇 屏蔽**：某个传感器不参与播报（保留配置）
- **实时状态**：每行显示当前值（温度/湿度/电量等），累计差值用电显示"实际值/差值"
- **播报音箱**：下拉选音箱（只列真正的智能音箱）

### 🧩 模板配置页

规则模板的参数配置（折叠分组）：

- **播报文案**：问候语/结束语/小贴士/鼓励语，手动填或大模型生成（批量一周/单条某天），7天循环
- **阈值**：温度高温/低温、湿度干燥/过湿、耗电排行、高功耗、PM2.5、任务、待办、设备故障
- **句式**：每条播报的措辞（占位符 {label}{now}{hum}{total} 等）
- **排除房间**：哪些房间不参与温度/湿度报警

### 🤖 大模型配置页

- **每日播报提示语** / **周期总结提示语**：可自定义，留空用默认
- **📋 填入示例提示语**：一键回填默认，改坏了可恢复
- **📚 多份存档**：保存多套提示语（命名），切换使用
- **生成长度**：max_tokens（生成太短可调大）

### 📜 历史页

- **日历**：看每天播报记录；**带 ⚠️ 的日期** = 检测到传感器异常
- **查看记录**：点日期看当天播报（日报/周报/月报/年报分色）
- **删除记录**：点 ✕ 或右键删除（**↩ 撤销可恢复**）
- **🛠️ 修复异常**：选 ⚠️ 日期，用前两天平均值替换异常值（传感器异常如一天耗电几十度）
- **🗑️ 清除当天数据**：当天统计数据异常时清掉当天（不影响其他天）

## 🔔 播报触发方式

1. **按钮实体**：加载项自动创建 `input_button.chuan_gan_qi_shi_ti_ri/zhou/yue/nian`，自动化里按下触发
2. **HTTP**：`POST /trigger?type=daily|weekly|monthly|yearly`
3. **Web UI**：播报页按钮

自动化示例（每晚 21 点播报）：
```yaml
- id: xiaomi_daily_broadcast
  alias: 每晚播报
  trigger:
    - platform: time
      at: "21:00:00"
  action:
    - service: input_button.press
      target:
        entity_id: input_button.chuan_gan_qi_shi_ti_ri
```

## 📋 终端任务计数

Claude Code 等终端工具 Stop hook 调 `POST /task` 记录任务完成数，播报会念"今天完成N个任务"。

## ❓ 常见问题

**音箱不响**
确认 HA 里音箱的 notify 实体可用（开发工具 → 通知），传感器配置页选对音箱（只列真正的智能音箱，手机/摄像机等不算）。

**LLM 不生成**
播报页引擎切"大模型"；大模型配置页确认填了 API 配置。若开了回退模板，失败会静默回退（看日志是否 `🤖 LLM 生成`）。

**播报没有某板块**
在"📋 播报栏目"勾上对应开关；或该板块无数据（如任务 0 条、所有灯关了）会自动省略。

**某个传感器不想播**
传感器配置里该行点 🔇 屏蔽。

**周/月/年统计不准**
历史页 → "清除当天的统计数据"（某天数据污染时只清当天）；或"🛠️ 修复异常"（某设备异常值用平均值修正）。
