# 🎙️ 小爱每日播报

把家里传感器状态生成中文播报稿，推到小米音箱朗读。支持每日/周/月/年播报、大模型引擎、可视化配置。

## 快速开始

1. 安装加载项（见 README）
2. 打开侧边栏 "小爱每日播报" → Web UI
3. **传感器配置**：选实体、填播报名/房间名/用途，选音箱
4. 点播报页 "📝 文字播报" 测试——出现全文说明连 HA 成功
5. 点 "📢 语音播报" 让音箱说话
6. 配大模型（可选）：播报页引擎切"大模型"，大模型配置页可自定义提示语

## 配置入口

| 页面 | 用途 |
|------|------|
| **📢 播报** | 语音/文字播报、引擎切换、日志、统计（传感器数/离线/天数） |
| **📋 播报栏目** | 选哪些内容播报（改完自动保存，模板/大模型都生效） |
| **⚙️ 传感器配置** | 实体映射（播报名/房间/用途/屏蔽/排序）、音箱、实时状态 |
| **🧩 模板配置** | 阈值、句式、一周文案（手动/大模型，可单条或批量生成） |
| **🤖 大模型配置** | 提示语、生成长度、多份提示语存档 |
| **📜 历史** | 日历查看每天播报、清除当天统计数据 |

## 播报触发

- **加载项按钮实体**（`input_button.chuan_gan_qi_shi_ti_ri/zhou/yue/nian`）：自动化/仪表盘按下触发
- **HTTP**：`POST /trigger?type=daily|weekly|monthly|yearly`（`&text_only=true` 只出文字）
- **Web UI**：播报页按钮

| 测试 | 操作 | 预期 |
|------|------|------|
| 连 HA | 播报页点"文字播报" | 出现播报全文，无认证失败 |

## 常见问题

**音箱不响**
先确认 HA 里音箱的 notify 实体可用（开发工具 → 通知），播报页传感器配置里选对音箱。只列真正的智能音箱，手机/摄像机等不算。

**LLM 不生成**
播报页引擎切"大模型"；大模型配置页确认填了 API 配置。若 `fallback_to_template=true`，失败会静默回退模板（看日志是否 `🤖 LLM 生成`）。

**播报内容没有某板块**
在"📋 播报栏目"勾上对应开关；或该板块无数据（如终端任务 0 条、所有灯都关了）会被省略。实体映射要填对。

**某个传感器不想播报**
传感器配置里该行点 🔇 屏蔽（保留在配置，不参与播报）。

**周/月/年统计不准**
历史页 → "清除当天的统计数据"（某天测试数据污染时只清当天）。
