# 🎙️ 小爱每日播报

定时把家里传感器状态生成中文播报稿，推送到小米音箱朗读。支持每日播报与周/月/年周期总结。

## 快速开始

1. 安装加载项（见 README）
2. 打开侧边栏 "小爱每日播报" → Web UI
3. 点 "📝 只看文字" 测试——日志出现全文说明连 HA 成功
4. 点 "📢 立即播报" 让音箱说话
5. 配置实体映射（Samba 编辑 `/share/xiaomi_broadcast/ha_daily_config.json`）和 DeepSeek（可选）

## 测试步骤

| 测试 | 操作 | 预期 |
|------|------|------|
| 连 HA | Web UI 点"只看文字" | 日志出现全文，无认证失败 |
| 播报 | 点"立即播报" | 音箱说话 |
| 大模型 | 配置 engine_mode=llm + 填 key，重启 | 日志 `🤖 LLM 生成` |
| 定时 | 把 weekday_hour 改成当前小时，保存 | 1 分钟内日志 `到点播报: daily` |

## 常见问题

**加载项启动失败 / 找不到配置**
首次启动会在 `/share/xiaomi_broadcast/` 生成默认配置。若没有，检查 Samba 是否装了、`share` 挂载是否正常。

**音箱不响**
先确认 HA 里音箱的 notify 实体可用（开发工具 → 通知）。检查 `speaker_notify` 是否填对。

**LLM 不生成**
确认填了 DeepSeek key，且 `engine_mode=llm`。若 `fallback_to_template=true`，失败会静默回退模板（看日志是否 `🤖 LLM 生成` 判断）。

**播报内容没有某板块**
某板块无数据会被自动省略（如终端任务 0 条、没有待办、所有灯都关了）。实体映射要填对。
