# 🎙️ 小爱每日播报 (Home Assistant Add-on)

让小米音箱播报家里的实时情况：温度、湿度、耗电量、实时功率、安全、空气质量、灯光、任务、待办、设备状态等。支持**每日/周/月/年**播报、**大模型引擎**，Web UI 一站式可视化配置。

## ✨ 功能总览

### 🗣️ 播报类型

- **日 / 周 / 月 / 年**四种总结，通过加载项自动创建的按钮实体触发，或 HTTP 接口 / 自动化调用
- 引擎切换（模板 / 大模型）在播报页顶栏

### 🤖 大模型引擎

- 直连 DeepSeek API 即兴组织语言（更自然），失败自动回退规则模板
- **提示语可自定义、可存档多份**：大模型配置页能保存多套提示语（如温馨风/极简风），不合适切换别的
- **自动更新方式三选一**：每天自动更新 / 每7天自动更新 / 关闭
- 生成方式灵活：批量生成一周，或**每个日期单独生成**一条

### 🧩 规则模板引擎

- **阈值**：温度高温/低温、湿度干燥/过湿、耗电排行、高功耗、PM2.5 等都可配
- **板块开关**：哪些内容播报（在"播报栏目"页，模板/大模型都生效）
- **句式**：每条播报的措辞可配（如"温度：{label}现在{now}度"），用占位符自定义

### 🌐 Web UI（六个页面）

| 页面 | 功能 |
|------|------|
| **📢 播报** | 语音/文字播报、引擎切换、句间停顿调节、日志（按类型分色）、统计（传感器总数/离线数/统计天数） |
| **📋 播报栏目** | 选哪些内容播报（问候语/温度/湿度/耗电量/实时功率/安全/空气质量/灯光/任务/待办/设备故障/鼓励语/小贴士/播报结束），改完自动保存 |
| **⚙️ 传感器配置** | 图形化选实体、填播报名/房间名/用途、拖动排序、屏蔽某个传感器、累计差值用电、实时状态徽章 |
| **🧩 模板配置** | 阈值、句式、一周文案（问候/结束/小贴士/鼓励），手动填或大模型生成（批量一周/单条某天） |
| **🤖 大模型配置** | 自定义提示语、生成长度、多份提示语存档、示例回填 |
| **📜 历史** | 日历查看每天播报（异常日期带 ⚠️）、删除记录（可撤销）、修复异常数据、清除当天数据 |

### 🔇 屏蔽传感器

- 某个传感器**不参与播报**，但保留在配置里（随时可恢复）
- 可单独设置每个传感器的"播报名"（如"冰箱"或"客厅冰箱"），同房间多设备不混淆

### ⚠️ 异常检测与修复

- 检测**某设备单日耗电超阈值**（传感器异常）的日期，日历上显示 ⚠️
- 一键修复：用该设备**前两天正常值的平均值**替换异常值（不是删除）

### ↩ 撤销 / ↪ 恢复

- 主菜单最右侧：撤销上一步操作（如删掉的历史记录可恢复）
- 删除历史记录自动进撤销栈，可靠恢复

## 🎙️ 音箱接入

加载项通过 HA 的 `notify.send_message` 让音箱说话。前提：
- 音箱已接入 HA（Xiaomi Home / miot 集成）
- 该集成提供 `notify` 域的 `play_text` 实体（HA 开发工具 → 通知里能看到）
- 传感器配置页可下拉选音箱（只列真正的智能音箱）

## 🔔 播报触发

- **加载项按钮实体**：`input_button.chuan_gan_qi_shi_ti_ri/zhou/yue/nian`（日/周/月/年），自动化/仪表盘按下触发
- **HTTP 接口**：`POST /trigger?type=daily|weekly|monthly|yearly`（`&text_only=true` 只看文字）
- **Web UI 按钮**：播报页"语音播报"/"文字播报"

## 📋 终端任务计数

终端工具的 Stop hook 可把"完成任务"记到加载项（播报里念"今天完成N个任务"）：
`POST /task`
