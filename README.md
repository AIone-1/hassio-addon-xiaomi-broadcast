# 🎙️ 小爱每日播报

让小米音箱播报家里实时情况的 Home Assistant 加载项。

- 🗣️ **每日/周/月/年**播报
- 🤖 **大模型引擎**（提示语可自定义、可存档）
- 🧩 **规则模板引擎**（阈值/板块开关/句式可配）
- 🌐 **Web UI 一站式可视化配置**（六页面：播报/播报栏目/传感器配置/模板配置/大模型配置/历史）
- ⚠️ **异常检测与修复**、↩ **撤销/恢复**、🔇 **屏蔽传感器**
