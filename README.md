# 🎙️ 小爱每日播报 (Home Assistant Add-on Repository)

让小米音箱播报家里实时情况的 Home Assistant 加载项。支持**每日/周/月/年**播报、**大模型引擎**、**可视化配置**的播报内容，Web UI 一站式操作。

## 安装

Home Assistant → **设置 → 加载项 → 加载项商店** → 右上角 **⋮ 菜单 → 仓库 (Repositories)** → 粘贴本仓库地址：

```
https://github.com/AIone-1/hassio-addon-xiaomi-broadcast
```

> ⚠️ 注意：仓库名是 `AIone-1`（大写字母 i），不是 `Alone-1`（小写 L）。

点击 **添加** → 商店出现 **小爱每日播报** → **安装** → **启动**。
